# Reused work

ONE DEGREE was built during the hackathon. One thing was carried over, and is declared
here as the rules require:

- **Control styling** from the team's earlier project, *Cosmic Collision Shield* (a
  space-debris tool, not related to this challenge): the glossy "material" surface,
  bevel, gloss-fill and glint-sweep tokens and the pill / round button pattern in
  `src/styles.css`. They were adapted (new palette for a black lunar sky, new components)
  rather than copied wholesale. The author of that project is the owner of this team;
  the adapted code is released here under Apache-2.0.

No other code, data or assets from earlier work were reused. The science engine, data
pipeline, 3D scene and every panel were written during the event.
