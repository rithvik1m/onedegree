# Use of AI ("Super Intelligence", SI)

NASA Space Apps asks every team to describe how SI tools were used. This is ours, in full.

- **Concept.** The owner used AI chat tools (including ChatGPT and Claude) to brainstorm
  and compare concepts for the Lunar Landing Site Navigator challenge and to draft the
  build plan. The owner chose the direction ("ONE DEGREE") and the priorities.
- **Code and data processing.** Claude Code (Anthropic, Claude Opus) wrote most of the
  code in this repository — the TypeScript app, the Python data scripts and the tests —
  under the owner's direction, during the hackathon (Nov 14–15, 2026). Commits made with
  it carry a `Co-Authored-By: Claude` trailer, and source files are marked in the commit
  history.
- **Research.** AI-assisted web research located NASA data products and mission facts;
  every source is cited in docs/DATA_SOURCES.md and was checked against the primary page
  or file (for example, the PDS label for the illumination map scaling).
- **Not AI-generated.** All scientific data come from NASA/JPL Horizons and NASA Goddard
  LOLA products. No AI-generated images, video or audio are used; the demo video is a
  screen recording of the running app with typed captions. The astronaut is a NASA 3D
  Resources model; the regolith detail texture is generated by deterministic code
  (noise + circles), not by an image model.
- **Verification.** Numbers were not taken on trust from the AI: the Reality Check panel
  and `npm test` re-derive them against NASA's own outputs.
